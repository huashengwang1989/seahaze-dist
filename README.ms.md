# SEA Haze — Sokongan

[English](README.md) · [华文](README.zh-Hans.md) · **Bahasa Melayu** · [தமிழ்](README.ta.md)

> **Tentang repositori ini:** SEA Haze bukan perisian sumber terbuka. Aplikasi ini akan tersedia di App Store Apple (akan datang). Repositori ini menempatkan halaman sokongan dan dasar privasinya, dan merupakan tempat untuk [melaporkan isu dan mencadangkan ciri baharu](../../issues).

SEA Haze memaparkan jerebu dan kualiti udara di Singapura, Malaysia dan Asia Tenggara: bacaan PM2.5, PSI dan IPU secara langsung, jerebu dan angin pada peta, titik panas kebakaran satelit di Sumatera dan Borneo, hujan, serta siklon tropika.

Tersedia untuk iPhone, iPad, Mac, Apple Watch dan Apple Vision Pro, dengan widget. Aplikasi ini dalam English, 华文, Bahasa Melayu dan தமிழ்.

- **Dasar Privasi:** [PRIVACY.ms.md](PRIVACY.ms.md) — aplikasi ini tidak mengumpul data peribadi.
- **Hubungi dan maklum balas:** [buka isu](../../issues) dalam repositori ini.

## Soalan lazim

**Dari mana datangnya data?**
Sumber awam: Agensi Alam Sekitar Kebangsaan Singapura (data.gov.sg), Jabatan Alam Sekitar Malaysia (APIMS), Open-Meteo (termasuk data model Copernicus CAMS), Sensor.Community, NASA FIRMS, RainViewer dan GDACS. Anda juga boleh menambah kunci API OpenAQ percuma anda sendiri dalam Tetapan untuk lebih banyak stesen.

**Mengapa sesetengah bacaan menunjukkan "≈"?**
"≈" menandakan anggaran model (Copernicus CAMS), dipaparkan hanya apabila tiada stesen pengukuran berdekatan. Ia bukan ukuran sebenar.

**Mengapa sesetengah data tidak dipaparkan?**
Sumber data mungkin tidak tersedia buat sementara waktu. Aplikasi tidak pernah memaparkan nilai rekaan atau lapuk: data yang lebih lama daripada 30 minit disembunyikan sehingga kemas kini baharu tiba. Ketik Muat semula di bahagian atas peta, atau tunggu kemas kini automatik seterusnya (setiap 15 minit).

**Bagaimana "Lokasi Saya" berfungsi?**
Jika anda membenarkan akses lokasi, aplikasi memilih stesen yang terdekat dengan anda. Lokasi anda kekal pada peranti anda. Anda boleh mematikannya di Tetapan → Lokasi.

**Bagaimana menambah widget?**
Pada iPhone atau iPad, sentuh dan tahan Skrin Utama, ketik Edit → Tambah Widget, dan cari "SEA Haze". Pada Mac, klik kanan desktop dan pilih Edit Widget. Edit widget untuk memilih stesen atau memaparkan lima kawasan Singapura.

**Bolehkah nama tempat dipaparkan dalam bahasa saya?**
Boleh. Dalam Tetapan, tetapkan Nama Lokasi kepada Bahasa Aplikasi. Pautan Senarai Nama Tempat di bahagian bawah Tetapan menyenaraikan semua nama yang diterjemah.

## Penghargaan data

- Mengandungi maklumat daripada Agensi Alam Sekitar Kebangsaan, digunakan di bawah terma Lesen Data Terbuka Singapura (data.gov.sg).
- Data Indeks Pencemar Udara daripada Jabatan Alam Sekitar Malaysia.
- Data cuaca dan kualiti udara oleh [Open-Meteo](https://open-meteo.com) (CC BY 4.0), termasuk maklumat Perkhidmatan Pemantauan Atmosfera Copernicus.
- Data kebakaran daripada NASA FIRMS. Radar daripada RainViewer. Amaran siklon daripada GDACS. Penderia komuniti daripada Sensor.Community.

## Penafian

SEA Haze ialah aplikasi bebas dan tidak bergabung dengan mana-mana agensi kerajaan atau pembekal data. Maklumatnya untuk rujukan umum sahaja dan bukan nasihat rasmi atau perubatan. Sentiasa ikut pengumuman rasmi, contohnya daripada NEA atau Jabatan Alam Sekitar Malaysia.
