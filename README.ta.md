# SEA Haze — ஆதரவு

[English](README.md) · [华文](README.zh-Hans.md) · [Bahasa Melayu](README.ms.md) · **தமிழ்**

சிங்கப்பூர், மலேசியா, தென்கிழக்கு ஆசியா முழுவதும் புகைமூட்டத்தையும் காற்றுத் தரத்தையும் SEA Haze காட்டுகிறது: நேரடி PM2.5, PSI, API அளவீடுகள், வரைபடத்தில் புகைமூட்டமும் காற்றும், சுமத்ரா மற்றும் போர்னியோவின் செயற்கைக்கோள் தீப்புள்ளிகள், மழை, வெப்பமண்டலப் புயல்கள்.

iPhone, iPad, Mac, Apple Watch, Apple Vision Pro ஆகியவற்றில் விட்ஜெட்டுகளுடன் கிடைக்கிறது. செயலி English, 华文, Bahasa Melayu, தமிழ் ஆகிய மொழிகளில் உள்ளது.

- **தனியுரிமைக் கொள்கை:** [PRIVACY.ta.md](PRIVACY.ta.md) — செயலி தனிப்பட்ட தரவு எதையும் சேகரிப்பதில்லை.
- **தொடர்பும் கருத்தும்:** இந்தக் களஞ்சியத்தில் [ஒரு சிக்கலைத் திறக்கவும்](../../issues).

## அடிக்கடி கேட்கப்படும் கேள்விகள்

**தரவு எங்கிருந்து வருகிறது?**
பொது மூலங்களிலிருந்து: சிங்கப்பூர் தேசிய சுற்றுப்புற வாரியம் (data.gov.sg), மலேசியச் சுற்றுச்சூழல் துறை (APIMS), Open-Meteo (Copernicus CAMS மாதிரித் தரவு உட்பட), Sensor.Community, NASA FIRMS, RainViewer, GDACS. மேலும் பல நிலையங்களுக்கு, அமைப்புகளில் உங்கள் சொந்த இலவச OpenAQ API விசையையும் சேர்க்கலாம்.

**சில அளவீடுகள் ஏன் "≈" எனக் காட்டுகின்றன?**
"≈" என்பது மாதிரி மதிப்பீட்டைக் (Copernicus CAMS) குறிக்கிறது; அருகில் அளவீட்டு நிலையம் இல்லாதபோது மட்டுமே காட்டப்படும். இது உண்மையான அளவீடு அல்ல.

**சில தரவுகள் ஏன் காட்டப்படவில்லை?**
தரவு மூலம் தற்காலிகமாகக் கிடைக்காமல் இருக்கலாம். செயலி கற்பனையான அல்லது பழைய மதிப்புகளை ஒருபோதும் காட்டாது: 30 நிமிடங்களுக்கு மேலான தரவு புதிய புதுப்பிப்பு வரும் வரை மறைக்கப்படும். வரைபடத்தின் மேலே உள்ள "புதுப்பி" என்பதைத் தட்டவும், அல்லது அடுத்த தானியங்கிப் புதுப்பிப்புக்கு (ஒவ்வொரு 15 நிமிடமும்) காத்திருக்கவும்.

**"எனக்கு அருகிலுள்ள நிலையம்" எவ்வாறு செயல்படுகிறது?**
நீங்கள் இருப்பிட அணுகலை அனுமதித்தால், செயலி உங்களுக்கு அருகிலுள்ள நிலையத்தைத் தேர்வு செய்யும். உங்கள் இருப்பிடம் உங்கள் சாதனத்திலேயே இருக்கும். அமைப்புகள் → இருப்பிடம் என்பதில் இதை முடக்கலாம்.

**விட்ஜெட்டை எவ்வாறு சேர்ப்பது?**
iPhone அல்லது iPad-இல், முகப்புத் திரையைத் தொட்டுப் பிடித்து, திருத்து → விட்ஜெட்டைச் சேர் என்பதைத் தட்டி, "SEA Haze" எனத் தேடவும். Mac-இல், மேசைத்திரையில் வலது கிளிக் செய்து விட்ஜெட்டுகளைத் திருத்து என்பதைத் தேர்வு செய்யவும். நிலையத்தைத் தேர்வு செய்ய அல்லது சிங்கப்பூரின் ஐந்து பகுதிகளைக் காட்ட, விட்ஜெட்டைத் திருத்தவும்.

**இடப் பெயர்களை என் மொழியில் பார்க்க முடியுமா?**
முடியும். அமைப்புகளின் மொழி அட்டையில், "இடப் பெயர்கள்" என்பதை "செயலி மொழி" என அமைக்கவும். அமைப்புகளின் கீழே உள்ள "இடப் பெயர் பட்டியல்" இணைப்பு, மொழிபெயர்க்கப்பட்ட அனைத்துப் பெயர்களையும் பட்டியலிடுகிறது.

## தரவு நன்றி

- சிங்கப்பூர் திறந்த தரவு உரிமத்தின் விதிமுறைகளின் கீழ் பெறப்பட்ட, தேசிய சுற்றுப்புற வாரியத்தின் தகவல்கள் அடங்கியுள்ளன (data.gov.sg).
- மலேசியச் சுற்றுச்சூழல் துறையின் காற்று மாசு குறியீட்டுத் தரவு.
- [Open-Meteo](https://open-meteo.com) வழங்கும் வானிலை மற்றும் காற்றுத் தரத் தரவு (CC BY 4.0), Copernicus வளிமண்டலக் கண்காணிப்புச் சேவைத் தகவல்கள் உட்பட.
- தீத் தரவு NASA FIRMS-இலிருந்து. ரேடார் RainViewer-இலிருந்து. புயல் எச்சரிக்கைகள் GDACS-இலிருந்து. சமூக உணரிகள் Sensor.Community-இலிருந்து.

## பொறுப்புத் துறப்பு

SEA Haze ஒரு சுயாதீனச் செயலி; எந்த அரசு நிறுவனத்துடனோ தரவு வழங்குநருடனோ இணைக்கப்படவில்லை. இதன் தகவல்கள் பொதுக் குறிப்புக்காக மட்டுமே; அதிகாரப்பூர்வ அல்லது மருத்துவ ஆலோசனை அல்ல. எப்போதும் அதிகாரப்பூர்வ அறிவிப்புகளைப் பின்பற்றவும், எ.கா. NEA அல்லது மலேசியச் சுற்றுச்சூழல் துறையின் அறிவிப்புகள்.
