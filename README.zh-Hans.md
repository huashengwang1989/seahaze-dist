# SEA Haze — 支持

[English](README.md) · **华文** · [Bahasa Melayu](README.ms.md) · [தமிழ்](README.ta.md)

SEA Haze 显示新加坡、马来西亚及东南亚的烟霾与空气质量：实时 PM2.5、PSI 和 API 读数，地图上的烟霾与风场，苏门答腊和婆罗洲的卫星火点，降雨，以及热带气旋。

适用于 iPhone、iPad、Mac、Apple Watch 和 Apple Vision Pro，并提供小组件。应用支持 English、华文、Bahasa Melayu 和 தமிழ்。

- **隐私政策：**[PRIVACY.zh-Hans.md](PRIVACY.zh-Hans.md)——本应用不收集任何个人数据。
- **联系与反馈：**请在本代码库[提交问题](../../issues)。

## 常见问题

**数据从哪里来？**
来自公开来源：新加坡国家环境局（data.gov.sg）、马来西亚环境局（APIMS）、Open-Meteo（包括哥白尼 CAMS 模型数据）、Sensor.Community、NASA FIRMS、RainViewer 和 GDACS。您也可以在设定中加入自己的免费 OpenAQ API 密钥，以显示更多监测站。

**为什么有些读数显示“≈”？**
“≈”表示模型估算值（哥白尼 CAMS），只在附近没有监测站时显示。它不是实测值。

**为什么有些数据没有显示？**
数据来源可能暂时无法使用。本应用绝不显示虚构或过时的数值：超过 30 分钟的数据会被隐藏，直到有新的更新。您可以点按地图顶部的“刷新”，或等待下一次自动更新（每 15 分钟）。

**“我的位置”如何运作？**
如果您允许位置访问，本应用会选出离您最近的监测站。您的位置只保留在您的设备上。您可以在设定 → 位置中关闭此功能。

**如何加入小组件？**
在 iPhone 或 iPad 上，按住主屏幕，点按“编辑”→“添加小组件”，然后搜索“SEA Haze”。在 Mac 上，右键点按桌面并选择“编辑小组件”。编辑小组件即可选择监测站，或显示新加坡五个区域。

**可以用我的语言显示地名吗？**
可以。在设定的语言卡片中，将“地名”设为“应用语言”。设定页面底部的“地名”链接会列出所有已翻译的名称。

## 数据来源鸣谢

- 包含新加坡国家环境局的资讯，依据《新加坡开放数据许可》使用（data.gov.sg）。
- 空气污染指数数据来自马来西亚环境局。
- 天气与空气质量数据由 [Open-Meteo](https://open-meteo.com) 提供（CC BY 4.0），包括哥白尼大气监测服务的资讯。
- 火点数据来自 NASA FIRMS。雷达来自 RainViewer。气旋警报来自 GDACS。社区传感器来自 Sensor.Community。
