# SEA Haze — Dasar Privasi

[English](PRIVACY.md) · [华文](PRIVACY.zh-Hans.md) · **Bahasa Melayu** · [தமிழ்](PRIVACY.ta.md)

Tarikh berkuat kuasa: 25 Oktober 2026

Dasar ini menerangkan cara aplikasi SEA Haze (“Aplikasi”) untuk iPhone, iPad, Mac, Apple Watch dan Apple Vision Pro, termasuk widgetnya, mengendalikan maklumat anda.

## Ringkasan

- Aplikasi ini **tidak mengumpul, menyimpan atau berkongsi sebarang maklumat peribadi atau data penggunaan**.
- **Tiada akaun, tiada log masuk, tiada iklan, tiada penjejakan dan tiada analitik**.
- Tetapan dan lokasi anda kekal **pada peranti anda**.

## 1. Maklumat yang disimpan pada peranti anda

Aplikasi menyimpan perkara berikut hanya pada peranti anda. Ia tidak pernah dihantar kepada pembangun:

- Tetapan anda (contohnya bahasa, lapisan peta, ambang amaran).
- Kunci API pilihan yang anda masukkan (OpenAQ, NASA FIRMS).
- Data kualiti udara, cuaca dan kebakaran yang dimuat turun baru-baru ini, supaya Aplikasi dapat dibuka dengan cepat (dipaparkan hanya jika kurang daripada 30 minit).
- Jika anda membenarkan akses lokasi: lokasi anggaran terakhir anda, digunakan untuk memilih stesen terdekat. Ia dikongsi dengan widget Aplikasi pada peranti yang sama melalui App Group, dan tidak ke tempat lain.

Memadam Aplikasi akan membuang semua maklumat ini. Anda juga boleh mengosongkan data yang dimuat turun di **Tetapan → Storan & Cache**.

## 2. Lokasi

Akses lokasi adalah pilihan (“Semasa Menggunakan Aplikasi”). Ia digunakan **hanya pada peranti anda** untuk memilih stesen kualiti udara yang terdekat dengan anda, dalam Aplikasi dan widgetnya. Lokasi anda **tidak pernah dihantar** kepada pembangun atau mana-mana pembekal data. Anda boleh mematikannya di Tetapan → Lokasi, atau dalam tetapan sistem peranti anda. Tanpanya, Aplikasi memaparkan Singapura Tengah secara lalai.

## 3. Pembekal data yang dihubungi oleh Aplikasi

Untuk memaparkan data langsung, Aplikasi memuat turun data awam terus daripada perkhidmatan berikut:

| Perkhidmatan | Apa yang dimuat turun oleh Aplikasi |
|---|---|
| data.gov.sg (Agensi Alam Sekitar Kebangsaan, Singapura) | Bacaan PM2.5, PM10 dan PSI |
| Jabatan Alam Sekitar Malaysia (APIMS) | Bacaan Indeks Pencemar Udara |
| Open-Meteo (termasuk data Copernicus CAMS) | Angin, awan, hujan dan kualiti udara model |
| Sensor.Community | Bacaan penderia kualiti udara komuniti |
| OpenAQ (hanya jika anda memasukkan kunci API sendiri) | Bacaan stesen kualiti udara |
| NASA FIRMS | Titik panas kebakaran satelit |
| RainViewer | Imej radar hujan |
| GDACS | Amaran siklon tropika |
| Amazon Web Services (jubin ketinggian terbuka) | Ketinggian rupa bumi untuk paparan 3D Vision Pro |
| Apple Maps | Imej peta |

Permintaan ini mengandungi kawasan atau koordinat serantau yang tetap, **bukan lokasi anda**. Seperti mana-mana laman web, perkhidmatan ini mungkin menerima maklumat teknikal standard seperti alamat IP anda, di bawah dasar privasi mereka sendiri. Kunci API pilihan anda hanya dihantar kepada perkhidmatan yang berkaitan.

## 4. Kecerdasan buatan

**Ringkasan Situasi** pilihan hanya menggunakan Model Asas **pada peranti** Apple (Apple Intelligence), jika tersedia pada peranti anda. Ringkasan ditulis sepenuhnya pada peranti anda daripada bacaan yang sudah dipaparkan dalam Aplikasi. **Tiada apa-apa dihantar kepada pembangun atau mana-mana pelayan AI** untuk ciri ini. Teks yang dijana oleh AI mungkin mengandungi kesilapan.

## 5. Pemberitahuan

Amaran kualiti udara dijana **secara setempat pada peranti anda**. Tiada pelayan pemberitahuan tolak digunakan.

## 6. Kanak-kanak

Aplikasi ini tidak mengumpul maklumat peribadi daripada sesiapa pun, termasuk kanak-kanak.

## 7. Perubahan pada masa hadapan

Versi akan datang mungkin mengumpul data penggunaan **tanpa nama** (contohnya ciri yang digunakan) untuk menambah baik Aplikasi. Data tersebut tidak akan mengenal pasti anda dan tidak akan dijual atau digunakan untuk pengiklanan. Dasar ini dan butiran privasi App Store akan dikemas kini **sebelum** sebarang pengumpulan sedemikian bermula. Perubahan lain pada dasar ini juga akan diterbitkan di sini dengan tarikh berkuat kuasa yang baharu.
